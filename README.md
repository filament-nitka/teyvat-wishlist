# ✦ Вишлист Тейвата

Фанатский тир-лист и вишлист персонажей Genshin Impact. Расставь персонажей по тирам, отметь, кто уже есть на аккаунте, поставь цели по созвездиям и оружию и скачай красивую картинку, чтобы поделиться с друзьями.

**Открыть сайт:** https://filament-nitka.github.io/teyvat-wishlist/

## Что умеет

- **Тир-лист** из пяти тиров: Избранники, Спутники, Попутчики, Прохожие, Мимо. Названия можно переименовать под себя.
- **Матрица** «хочу / полезен»: персонажей можно расставить по полю.
- **Вишлист:** какие созвездия хочется (шкала показывает, сколько уже есть и сколько осталось), какое оружие и пробуждение.
- **Отметки:** есть ли персонаж на аккаунте, ♥ вайфу-фактор, хочу скин.
- **Кольца у аватарок** показывают тип персонажа: лимитированный 5★, стандартный 5★, 4★, бесплатный, скоро выйдет.
- **Фильтры** по стихии, оружию, редкости, баннеру и наличию на аккаунте.
- **Кому фармим артефакты?** — раз в день выбирает персонажа с анимацией молитвы.
- **Ачивки:** 18 секретных достижений, которые открываются по ходу заполнения.
- **Скачать тир-лист** одной картинкой PNG.
- Русский и английский язык, светлая и тёмная тема.

## Как пользоваться

- Перетаскивай карточки между тирами мышкой, на телефоне — долгим нажатием и движением пальца.
- Нажми на карточку, чтобы открыть подробности: аккаунт, созвездия, оружие, заметки.
- Правая кнопка мыши (на телефоне — долгое нажатие без движения) открывает быстрое меню.

## Где хранятся данные

Твой список хранится только в твоём браузере, на сервер ничего не отправляется. Если почистить данные сайта или открыть его в другом браузере, список будет пустым. Чтобы не потерять его, сохраняй копию через кнопку **«Мои данные»**: там же её можно загрузить обратно.
