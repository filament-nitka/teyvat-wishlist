# Вишлист Тейвата

Тир-лист и вишлист персонажей Genshin Impact. Каждый, кто открывает сайт, составляет свой список: он хранится в его браузере.

## Что лежит в папке

- `index.html` — сам сайт. Его править не нужно.
- `characters.js` — список персонажей. Его ты будешь править, когда выходят новые.
- `images.js` — все картинки, которые уже были, упакованы в один файл. Его открывать и править не нужно.
- папка `images` — для новых картинок, которые ты будешь добавлять сама (её пока нет, появится при первой загрузке).

## Как выложить на GitHub Pages

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажми **New repository** (зелёная кнопка или «+» вверху справа).
   - Название, например, `teyvat-wishlist`.
   - Выбери **Public**: бесплатный GitHub Pages работает только с публичными репозиториями.
   - Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
4. Перетащи `index.html`, `images.js`, `characters.js` и `README.md`, затем нажми **Commit changes**. Это всего четыре файла, лимит GitHub на 100 файлов не мешает.
5. Открой **Settings → Pages**. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)**, нажми **Save**.
6. Через одну-две минуты наверху этой страницы появится ссылка вида
   `https://твой-ник.github.io/teyvat-wishlist/`. Её и кидай подружкам.

## Как добавить нового персонажа

1. Открой `characters.js` в репозитории и нажми значок карандаша (**Edit this file**).
2. Скопируй любую похожую строку и вставь её в конец списка, перед строкой `];`.
3. Поменяй поля:
   - `id` — придумай **новый** уникальный код, например `"new_mitya"`.
   - `ru`, `en` — имя.
   - `element`, `weapon`, `rarity`, `status`, `banner` — расшифровка вверху файла.
   - `avatar`, `background` — пути к картинкам или `""`, если картинок нет.
4. Нажми **Commit changes**. Через минуту сайт обновится.

Пример:

```js
  {id: "new_mitya", ru: "Митя", en: "Mitya", element: "E", weapon: "s", rarity: 5, status: "playable", banner: "limited", avatar: "images/mitya.webp", background: ""},
```

**Когда персонаж из анонса выходит**, найди его строку и поменяй `status: "soon"` на `"playable"`, допиши оружие, редкость и `banner`. `id` при этом не трогай.

## Как добавить или заменить картинку

1. В репозитории нажми **Add file → Upload files** и перетащи папку `images` с новой картинкой внутри (так GitHub создаст папку, если её ещё нет). Если папка `images` уже есть, можно открыть её и загрузить файл прямо туда. Лучше `.webp` или `.jpg` и небольшого размера: аватарке хватит 300 пикселей, фону 500.
2. В `characters.js` впиши путь в `avatar` или `background`, например `"images/mitya.webp"`.

Чтобы заменить старую картинку из `images.js`, просто загрузи новую в папку `images` и впиши её путь в строку персонажа: путь из `characters.js` важнее.

## Важно

- **Никогда не меняй `id` у существующих персонажей.** По нему у всех хранятся тиры, вишлисты и отметки «есть на аккаунте». Сменишь `id` — у людей этот персонаж «обнулится».
- Если после правки сайт стал пустым, скорее всего, в `characters.js` потерялась запятая в конце строки или кавычка. Открой файл и сравни сломанную строку с соседними.
- Списки людей хранятся в их браузерах. Если почистить данные сайта или открыть его в другом браузере, список будет пустым. Сохранить его можно через кнопку **«Мои данные»**: скопировать или скачать файл, а потом загрузить обратно.
- Репозиторий публичный: файлы, включая картинки, сможет увидеть любой.

## Как перенести свой список из Claude

1. В версии на Claude нажми **«Мои данные»** и скопируй текст.
2. На сайте нажми **«Мои данные»**, вставь текст и нажми **«Загрузить»**.

Перенесутся тиры, вишлист, отметки аккаунта, свои персонажи и названия тиров.
